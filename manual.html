操作手冊

以「天時、地利、人和」三維度交織 52 週時間線，規劃全年度行銷檔期與整合行銷渠道。

什麼是「天時、地利、人和」

  • 天時：目標市場（TA）真正會過的節慶檔期——不是品牌自己的生日或週年慶，而是消費者本來就會關注的日子（雙11、母親節、中秋節……）
  • 地利：品牌與消費者實際發生交易的通路，例如官網商城、實體門市或特殊通路
  • 人和：自媒體、他媒體、CRM、活動、策展、異業六大整合行銷工具，把訊息精準打在 TA 身上
ROAS 的狂飆從來不單純取決於廣告投放操作，而是當「流量（人和）」「情境（天時）」「定位（地利）」三者連成一線時的必然轉換結果。

操作步驟

  1. 填品牌名稱、產業類別、目標客群（TA）；也可以先點上方快速範例按鈕，套用一組虛構品牌範例再自行修改
  2. 「地利」區塊列出品牌實際的交易通路（例如官方網站商城、門市），並標記通路類型（網路商城／官網、實體店／門市、特殊通路）
  3. 「人和」區塊勾選目前實際有在用的整合行銷工具，沒有在用的不用勾——沒勾的工具不會出現在行事曆建議中
  4. 可調整「行事曆起始週」與「涵蓋週數」，規劃特定期間（例如只看第40-52週的旺季衝刺）或跨年度的行事曆
  5. 按「產生我的全年度行事曆」：沒有 AI 金鑰也沒關係，規則式引擎會依你填的產業類別自動排出 12-18 個檔期，並依「地利」通路類型與「人和」優先序配對建議
  6. 想要文案更貼合你的品牌，可展開「AI 優化設定」，填入自己的 API 金鑰再按「產生」——這次會請 AI 針對每個檔期把「戰略整合共鳴」文案改寫得更具體，單一檔期優化失敗會自動退回規則式文字，不會讓整份行事曆開天窗

52 週時間軸總覽

橫軸是 52（或你設定的）週時間線，縱軸交叉「天時／地利／人和」三列。有排到檔期的週次會顯示較寬的卡片（檔期名稱、建議地利、建議人和標籤）；沒有檔期的週次只留一條細窄的刻度，方便你一眼看出全年度的行銷節奏疏密。下方另有一份「檔期總覽表」，用表格方式列出完整明細，方便橫向比較或列印。

部分檔期是農曆日期（標示「農曆」），實際日期會依當年月曆有數週的落差，請自行對照當年月曆微調週次。

快速範例

表單上方有 5 個快速範例按鈕，涵蓋美妝保養、餐飲、3C科技、親子教育、健康保健五個不同產業的虛構品牌情境，方便快速上手或觀察不同產業會排出哪些不同的檔期組合。點下去會直接覆蓋目前表單內容，會先詢問是否確定覆蓋。

隱私說明

  • 你填寫的品牌變數、通路與人和勾選、產生出來的行事曆，都只存在自己瀏覽器的 localStorage，不會傳送到任何伺服器；換一台電腦或清除瀏覽器資料就會不見，重要內容建議下載成檔案備份
  • AI 金鑰同樣只存在瀏覽器的 localStorage；按下「產生」且有填金鑰時，你的品牌資訊與規則式排出的檔期清單會直接連線送到你選擇的服務商官方 API，不會經過本工具作者或任何第三方伺服器
  • 「重設為範例」會清除瀏覽器裡目前的表單內容與生成結果

使用警語

請注意：
  • 本工具的範例與規則式引擎內容皆為虛構示範，不代表任何真實品牌；只有你主動填入 API 金鑰並按下「產生」時才會呼叫語言模型，不使用這項功能就完全不會連網
  • 節慶檔期週次為近似值，農曆節日請務必對照當年月曆自行調整
  • 請勿在任何欄位輸入真實個資、公司機密，或不希望被 AI 服務留存的敏感資訊
  • AI 生成的內容可能包含錯誤或不合時宜的建議，實際排入年度計畫前務必自行檢查與調整
  • 使用 AI 生成功能所產生的 API 費用由你與所選服務商的方案自行負擔，本工具不會向你收費
